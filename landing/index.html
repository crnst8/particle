Modern publications have made reading unbearable,
this is the fastest way to fix it.

Demo GitHub

The demo library stays in your browser; the server stores nothing. Self-hosted particle saves to your SQLite file.

Run your own

docker run -d -p 4747:4747 -v particle-data:/app/data ghcr.io/crnst8/particle:latest

That's the whole install — open localhost:4747 and paste a URL. Docker Compose and a plain npm start both work too: see the README.
